# Dark Patterns

Dark patterns are user interface designs that manipulate users into making choices they would not make if the interface were neutral. 

In the context of privacy consent, common dark patterns include: making the "accept all" option large, prominently colored, and easy to click while making the "manage preferences" or "decline" option small, gray, and buried in secondary menus; presenting consent choices in ways that make the privacy-protective option sound like it will break the service; using double negatives ("uncheck this box to not receive marketing communications"); and requiring users to click through multiple screens to decline data use while allowing acceptance with a single click.
